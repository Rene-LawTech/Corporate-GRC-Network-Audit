# Corporate Data Privacy Infrastructure & GRC Alignment Audit

## 📌 Project Overview
This project demonstrates an end-to-end Governance, Risk, and Compliance (GRC) implementation. It bridges the gap between **English Private Law standards** (liability reduction, data privacy mandates) and **technical network infrastructure** (Cisco architecture, firewall controls). 

The repository contains a secure network topology designed to mitigate corporate data exposure alongside a formal corporate Information Security Policy (ISP).

---

## 🛠️ Phase 1: Technical Infrastructure (Cisco CCNA & Security+)
To enforce data isolation, the internal enterprise network was built and tested using Cisco systems. 

### Key Technical Controls Implemented:
* **Network Segmentation:** Configured Layer 3 VLANs to completely isolate Guest traffic from the Corporate Operations and Finance cores.
* **Access Control Lists (ACLs):** Deployed Cisco Extended ACLs to filter packets dynamically based on source, destination, and protocols—enforcing the **Principle of Least Privilege**.
* **Administrative Security:** Disabled unsecured Telnet lines (Port 23) across all switches, enforcing encrypted **SSH (Port 22)** for all administrative device management.

## ⚖️ Phase 2: Corporate Policy & Governance (LL.B Private Law)
A technical network is only as effective as the governance structure driving it. I authored a binding corporate directive mapping our physical network configurations against international regulatory compliance standards.

### Strategic Objectives Met:
* **Regulatory Alignment:** Mapped technical access controls directly to **GDPR Article 25 (Privacy by Design)** and **NIST CSF** frameworks.
* **Liability Mitigation:** Outlined clear administrative boundaries to reduce corporate compliance liability and protect proprietary client data points.
